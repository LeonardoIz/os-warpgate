os-warpgate

OPNsense plugin repository for Warpgate, the smart SSH, HTTPS, MySQL, PostgreSQL, Kubernetes, VNC and RDP bastion.

Install this repo

On the router, as root:

fetch -o /usr/local/etc/pkg/repos/ https://leonardoiz.github.io/os-warpgate/warpgate.conf https://leonardoiz.github.io/os-warpgate/warpgate.pub
pkg update

Then install os-warpgate from System → Firmware → Plugins. Updates arrive with normal firmware updates.

The repository is signed. To check the key, openssl pkey -pubin -in /usr/local/etc/pkg/repos/warpgate.pub -outform DER | sha256 must print:

7f17a6885c0bc2d3f38c3dcab1d79446c948f171ad2f4fe840657b08057aa127

Set up

In Services → Warpgate → Settings: enable, choose the protocols and ports, Apply. The initial admin password is shown on that page after the first start. Uninstalling keeps Warpgate's data in /var/db/warpgate.

Packages
